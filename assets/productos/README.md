# Fotos y video del producto (para el bot de WhatsApp)

Sube aquí las imágenes/video que el bot enviará a los clientes. Usa EXACTAMENTE estos nombres
para que las URLs coincidan con la configuración del bot:

- `producto.jpg`  → foto del conjunto (ej. la foto plana negra)
- `modelo.jpg`    → foto del conjunto puesto (opcional)
- `colores.jpg`   → foto que muestre los colores disponibles (negro, blanco, rojo, verde, morado)
- `video.mp4`     → video corto del producto (opcional, liviano < 15 MB)

Quedan públicos en, por ejemplo:
`https://mtavera99.github.io/impermeables/assets/productos/producto.jpg`
